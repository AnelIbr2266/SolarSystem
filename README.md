# Солнечная система

Учебное приложение на C++ и Qt, разработанное для изучения основ объектно-ориентированного программирования.
Программа отображает Солнце и восемь планет Солнечной системы. Планеты движутся по орбитам, а пользователь может просматривать их характеристики, добавлять новые планеты и удалять существующие.

## Функциональные возможности

- отображение Солнца и восьми планет;
- движение планет по орбитам;
- запуск и остановка анимации;
- выбор небесного тела нажатием мыши или через список;
- просмотр характеристик выбранного объекта;
- добавление новых планет;
- удаление выбранных планет;
- сортировка объектов по расстоянию от Солнца.

## Используемые технологии

- **C++** — язык программирования;
- **Qt 6** — создание графического интерфейса и отрисовка объектов;
- **CMake** — система сборки проекта.

## Установка и запуск

Для сборки проекта необходимы:
1. Qt 6;
2. компилятор C++;
3. CMake;
4. среда разработки, поддерживающая C++ и Qt.

Откройте проект в среде разработки, настройте сборку с использованием установленной версии Qt и выполните сборку.
После успешной компиляции можно запустить исполняемый файл приложения.

## Основные классы

- **SpaceObject** — абстрактный базовый класс. Содержит общие характеристики небесных тел и методы для работы с ними.
- **Star** — класс звезды, наследуется от `SpaceObject`.
- **Planet** — класс планеты, наследуется от `SpaceObject`.
- **SolarSystem** — класс для хранения небесных тел, добавления, удаления, поиска и сортировки объектов.
- **SceneWidget** — виджет Qt, отвечающий за отображение Солнечной системы и движение планет.
- **MainWindow** — главное окно приложения, объединяющее графическую сцену и элементы управления.

## Управление программой

| Элемент интерфейса | Назначение |
|---|---|
| Старт / Стоп | Запуск и остановка движения планет |
| Список небесных тел | Выбор объекта |
| Добавить планету | Открытие формы создания новой планеты |
| Удалить планету | Удаление выбранной планеты |
| Сортировать по расстоянию | Упорядочивание объектов по расстоянию от Солнца |
| Область отображения | Просмотр Солнца, планет и их орбит |

## Основные принципы ООП в проекте

В программе используются основные принципы объектно-ориентированного программирования:

- **Инкапсуляция** — характеристики объектов хранятся внутри классов и изменяются через методы.
- **Наследование** — классы `Star` и `Planet` наследуются от общего класса `SpaceObject`.
- **Полиморфизм** — виртуальные методы позволяют получать название типа и описание конкретного объекта через указатель на базовый класс.
- **Абстракция** — `SpaceObject` задаёт общий набор характеристик и поведения небесных тел.

Также в базовом классе перегружены операторы сравнения.

## Назначение проекта

Проект предназначен для демонстрации практического применения классов, объектов, наследования, инкапсуляции, полиморфизма и перегрузки операторов в языке C++ с использованием библиотеки Qt.
